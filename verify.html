Understanding Verification

Code Lookup

Entering a verification code confirms that we created a document with that code and retrieves its metadata. This is useful for quickly checking details like message count and date range.

PDF Upload (Strongest Proof)

Uploading the PDF computes a SHA-256 hash (a unique digital fingerprint) of the file and compares it to what we stored when the document was created. If they match, the document is byte-for-byte identical to our original - proving it hasn't been modified in any way.

Security Features

SHA-256 Hash: Cryptographic fingerprint - any modification changes it completely
Digital Signature: Proves the document was created by Filtered
Timestamp: Cryptographic proof of when the document was created
Unique Code: Each export gets a random 12-character verification code
